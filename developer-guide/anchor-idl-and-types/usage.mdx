RugFreePump publishes its Anchor IDL and generated TypeScript types as the machine-readable integration artifacts for the on-chain program.

The **Anchor IDL** describes the deployed program interface, including instructions, arguments, accounts, account types, events, and defined types.

The **generated TypeScript types** provide the corresponding TypeScript representation of the IDL for integrations using TypeScript.

These artifacts are deployment-specific and must correspond to the RugFreePump program being integrated with.

## Integration References

The IDL provides the complete machine-readable representation of the deployed program interface.

The Developer Guide provides detailed integration requirements for the public instruction currently documented for direct integration:

* [Buy](../on-chain-integration/buy)

Use the instruction reference for the accounts, arguments, PDA derivations, state requirements, and other transaction-level information required by that instruction.

## Artifact Consistency

The following artifacts must correspond to the same deployed program interface:

```text
Program ID
    +
Deployed program
    +
Anchor IDL
    +
Generated TypeScript types
```

A change to the RugFreePump hosted application does not necessarily represent a change to the on-chain program or its IDL.

Direct integrations should use the published IDL and generated types corresponding to the target deployment.
