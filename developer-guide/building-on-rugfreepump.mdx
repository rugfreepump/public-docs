RugFreePump exposes its protocol through a Solana program and its public Anchor interface. Developers can integrate directly with the on-chain program using standard Solana tooling.

The RugFreePump web application and backend infrastructure are not required for direct on-chain integration.

## Development environments

RugFreePump provides separate Solana deployments for development and production.

Use **Devnet** for development, integration testing, transaction construction, and program interaction testing.

Use **Mainnet** for production integrations and real user transactions.

Use the program ID corresponding to the target Solana cluster.

For production integrations, use the Mainnet program ID with the `mainnet-beta` cluster.

## Public integration surface

The Developer Guide currently provides a detailed integration reference for:

| Instruction | Purpose                                                       |
| ----------- | ------------------------------------------------------------- |
| `buy`       | Purchases tokens from an active bonding-curve sale using SOL. |

The `buy` instruction is an Anchor program entry point and can be invoked directly by Solana clients or by other Solana programs through CPI, subject to the account, signer, authority, and state requirements enforced by the instruction.

The complete deployed program interface remains available through the Anchor IDL.

## Protocol interface

Direct integrations should use the on-chain program interface and the corresponding deployment artifacts.

The primary integration artifacts are:

* RugFreePump program ID
* Anchor IDL
* Generated TypeScript types, where applicable
* Instruction account definitions
* Instruction arguments
* Program account state
* Events emitted by the program
* Instruction-specific PDA definitions and external accounts

See [Anchor IDL & Types](./anchor-idl-and-types/usage) for the available IDL and generated types.

## Protocol Accounting Units

RugFreePump uses defined integer representations for protocol accounting.

| Metric / Asset        | Protocol Representation       | Smallest Base Unit | Conversion Rate                        |
| --------------------- | ----------------------------- | ------------------ | -------------------------------------- |
| SOL                   | Lamports                      | Lamport            | `1 SOL = 1,000,000,000 lamports (10⁹)` |
| SPL Token             | 6-decimal fixed-point         | Base unit          | `1 token = 1,000,000 base units (10⁶)` |
| USD                   | 2-decimal fixed-point         | Unit               | `$1.00 = 100 units (10²)`              |
| percentage            | basis points                  | Basis point (bps)  | `100% = 10,000 bps (1% = 100 bps)`     |
| Time                  | Unix timestamp                | Second             | `1 second = 1 (Unix timestamp)`        |


## On-chain state

The RugFreePump program and its Solana accounts are the authoritative source of protocol state.

Off-chain applications may provide interfaces, indexing, caching, or other supporting functionality, but those services are not required for direct protocol interaction.

The [Buy](./on-chain-integration/buy) reference documents the accounts, arguments, state requirements, external accounts, and transaction requirements needed to construct the instruction.

## CPI compatibility

RugFreePump's public on-chain instructions are Anchor program entry points and can be invoked by other Solana programs through cross-program invocation (CPI).

A CPI caller must satisfy the same validation requirements enforced by the target instruction.

RugFreePump does not currently provide a maintained CPI wrapper or Rust integration crate.

A dedicated CPI wrapper and Rust crate are planned as future developer tooling.
