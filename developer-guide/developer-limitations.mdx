title: "Developer Limitations"
description: "Understand the current scope and boundaries of the RugFreePump public developer interface."
---

The public developer interface is the deployed **RugFreePump Solana program** and its published [Anchor IDL & Types](./anchor-idl-and-types).

RugFreePump does not provide off-chain infrastructure as part of its public developer interface. Direct integrations must interact with the on-chain program using standard Solana tooling.

## What RugFreePump Does Not Provide

RugFreePump currently does not provide the following public infrastructure or tooling:

* **No off-chain SDK:** RugFreePump does not currently provide an official off-chain SDK.
* **No public REST API:** RugFreePump does not provide REST API endpoints for third-party developer integrations. The hosted application uses internal REST APIs that may change or be discontinued without notice.
* **No managed RPC or transaction relaying:** Integrators must provide their own RPC access, transaction submission, transaction fees, and retry infrastructure.
* **No managed indexing or data services:** Developers must manage their own caching, indexing, event monitoring, and application data infrastructure.
* **No CPI wrapper or Rust crate:** There is currently no official CPI wrapper or Rust integration crate.

Developers are responsible for the off-chain infrastructure, wallet handling, and application architecture required by their own integrations.

## Solana Deployments

RugFreePump maintains separate on-chain deployments across supported Solana clusters:

* **Devnet:** Provided for development, integration testing, and protocol testing.
* **Mainnet:** The production deployment for live protocol interactions.

Both deployments are maintained against the same RugFreePump program interface, which is defined by the published [Anchor IDL & Types](./anchor-idl-and-types).

Program IDs and deployment-specific configurations must match the target Solana cluster.

## Future Developer Tooling

RugFreePump plans to introduce the following official developer tooling in future releases:

* A dedicated **CPI wrapper**
* A dedicated **Rust integration crate**

Until these tools are officially released, third-party integrations should use the published on-chain program interface and standard Solana development tools.
