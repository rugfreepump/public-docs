title: "Developer Limitations & Scope"
description: "Understand the integration boundaries and infrastructure requirements of RugFreePump."
---

The sole integration boundary is the deployed **on-chain Solana program** and its published **Anchor IDL**. RugFreePump does not provide a managed developer platform, off-chain SDKs, or public APIs. 

### Component Scope

| Component | Scope | Developer Requirements |
| :--- | :--- | :--- |
| **On-Chain Program** | **Public** | Interoperable via standard Solana tools and Cross-Program Invocations (CPI). |
| **Hosted App / Backend** | **Private** | Internal indexing, DBs, and WebSockets. Subject to breaking changes without notice. |
| **Transaction Execution** | **External** | Integrators must provide their own RPCs, wallets, gas management, and retry logic. |

### Environment Configuration

RugFreePump maintains distinct environments for Devnet and Mainnet:
* **Target Mapping:** Applications must target the correct cluster addresses. Devnet settings do not apply to Mainnet.
* **External Dependencies:** Oracle accounts (like Pyth) and external program addresses must match the target cluster.
* View current deployment addresses on the [Anchor IDL & Types](./anchor-idl-and-types) page.

### Future Roadmap
Planned official tooling includes:
* A dedicated **Rust integration crate**
* An official **CPI wrapper**

### Support Policy
Documentation covers only the public on-chain interface. Integrators are entirely responsible for their own app architecture, data indexing, node providers, and transaction lifecycle. Interface updates are published directly via the [Anchor IDL & Types](./anchor-idl-and-types) page.
