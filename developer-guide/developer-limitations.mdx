title: "Developer Limitations & Scope"
description: "Understand the current scope, infrastructure boundaries, and integration requirements of the RugFreePump protocol."
---

The compatibility boundary for integrating with RugFreePump is the deployed **on-chain Solana program** and its published **Anchor IDL**.

RugFreePump does not currently provide a managed developer platform, official off-chain SDK, or public REST API. Direct integrations should treat the Solana blockchain and the deployed RugFreePump program as the authoritative source of protocol state.

### Architectural Boundaries

| System Component           | Scope        | Developer Implications                                                                                                                                                     |
| :------------------------- | :----------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **On-Chain Program & IDL** | **Public**   | Authoritative protocol interface. Interoperable through standard Solana tooling and Cross-Program Invocation (CPI).                                                        |
| **Hosted App & Backend**   | **Private**  | Internal infrastructure for application functionality such as indexing, databases, APIs, and WebSockets. Subject to change independently of the public on-chain interface. |
| **Transaction Execution**  | **External** | Integrators must provide their own RPC access, wallets, transaction submission, transaction-fee handling, confirmation, and retry logic.                                   |

### Environment Configuration

RugFreePump maintains separate Devnet and Mainnet deployments.

* **Target Mapping:** Ensure your application targets the correct Solana cluster and corresponding program deployment.
* **Shared Interface:** Devnet and Mainnet are maintained against the same RugFreePump program interface so developers can test against the same protocol interface intended for production.
* **External Dependencies:** Required external accounts and program addresses must satisfy the requirements of the target cluster and instruction.
* View the current deployment addresses and published interface artifacts on the [Anchor IDL & Types](./anchor-idl-and-types) page.

### Future Tooling Roadmap

While not currently available, RugFreePump plans to release additional official developer tooling in future updates:

* A dedicated **Rust integration crate**
* An official **CPI wrapper**

### Support Policy

The Developer Guide documents the public on-chain interface and its integration requirements.

Developers are responsible for their own application architecture, indexing infrastructure, RPC providers, wallets, transaction lifecycle management, monitoring, and other external dependencies.

When the public on-chain interface changes, the corresponding [Anchor IDL & Types](./anchor-idl-and-types) artifacts are updated to reflect the current program interface.
