---
title: "Developer Limitations"
description: "Understand the current scope and boundaries of the RugFreePump public developer interface."
---

The public developer interface is strictly limited to the deployed **RugFreePump Solana program** and its published [Anchor IDL & Types](./anchor-idl-and-types). 

RugFreePump does not provide off-chain infrastructure as part of its public developer interface. Direct integrations must interact with the on-chain program using standard Solana tooling.

## What RugFreePump Does Not Provide

RugFreePump currently does not provide the following public infrastructure or tooling:

*   **No off-chain SDK:** No official off-chain SDK is provided or required.
*   **No public REST API:** Internal backend services are private infrastructure and subject to change without notice.
*   **No managed RPC or relaying:** Integrators must supply their own RPC nodes, transaction execution, and gas/retry management.
*   **No data indexing:** Developers must manage their own data caching, indexing, and event monitoring.
*   **No temporary helper crates:** There is currently no official CPI wrapper or Rust integration crate available.

Developers are fully responsible for the off-chain infrastructure, wallet handling, and application architecture required by their own integrations.

## Solana Deployments

RugFreePump maintains separate, independent on-chain deployments across clusters:

*   **Devnet:** Provided for development, integration testing, and protocol staging.
*   **Mainnet:** The authoritative production deployment for live protocol interactions.

Both deployments share the exact same underlying RugFreePump program interface, which is defined in the [Anchor IDL & Types](./anchor-idl-and-types) documentation. However, target program IDs, oracle endpoints (e.g., Pyth), and configuration parameters must match the active cluster environment.

## Future Developer Tooling

To streamline direct protocol integrations, RugFreePump plans to introduce the following official tooling in future releases:

*   A dedicated **CPI wrapper**
*   A dedicated **Rust integration crate**

Until these tools are officially released, all third-party integrations must utilize the published on-chain program interface and standard Solana development tools.
