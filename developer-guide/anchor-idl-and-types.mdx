RugFreePump publishes its **Anchor IDL** and **TypeScript types** as the definitive, machine-readable specification of its public on-chain interface.

* **Anchor IDL:** Defines the complete program structure, including instructions, account layouts, arguments, events, custom errors, and custom types.
* **TypeScript Types:** Provides strongly-typed representations of the IDL components for safe, predictable client-side integration.

RugFreePump maintains strict parity across all deployments. Because the program interface is identical across Devnet and Mainnet, the published IDL and types serve as a unified spec rather than cluster-specific variants.

## Interface Synchronization & Versioning

The published IDL and generated TypeScript types are strictly coupled to the program interface state. Updates to these artifacts are triggered exclusively by breaking or non-breaking structural modifications, including:

* **Instruction Definitions:** Modifications to method names, entry points, or routing logic.
* **Arguments & Signatures:** Changes to parameter sizing, byte order, or required signers.
* **Account Structures:** Alterations to state-account schemas, sizing, or relative relationships.
* **Telemetry & Errors:** Variations in program-emitted events or custom error codes.

Devnet and Mainnet are explicitly locked to the same interface version. This guarantees that integrations successfully verified on Devnet will execute safely against the live production deployment.
