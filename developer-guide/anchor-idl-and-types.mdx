RugFreePump publishes its **Anchor IDL** and **TypeScript types** as the machine-readable representation of its public on-chain program interface.

* **Anchor IDL:** Describes the program interface, including instructions, account layouts, arguments, events, errors, and defined types.
* **TypeScript Types:** Provides the generated TypeScript representation of the IDL for strongly typed client integrations.

RugFreePump maintains the identical program interface across its supported Devnet and Mainnet deployments. The published IDL and TypeScript types represent a shared protocol interface rather than separate, cluster-specific variants.

A Program ID identifies a specific deployment and operates independently of the interface layout. Updating a cluster deployment address does not require new IDL or TypeScript artifacts if the underlying program interface remains unchanged.
:::

## Interface Synchronization & Versioning

The published IDL and generated TypeScript types serve as the live reference for the current RugFreePump program interface.

:::tip Latency Verification
**Last updated:** `September 22, 2026`

The timestamp above marks the latest published state of the IDL and TypeScript artifacts. Use this date as your baseline reference to ensure your local implementation maps to the current active specification.
:::

Interface updates are triggered when contract modifications alter the underlying layout. Examples include:

* **Instructions:** Changes to public instruction definitions or entry points.
* **Arguments:** Modifications to instruction parameters or their data types.
* **Accounts:** Alterations to account schemas or structural relationships exposed by the interface.
* **Events:** Adjustments to program-emitted event definitions.
* **Errors and Types:** Additions or changes to custom errors and defined types represented in the IDL.

While RugFreePump minimizes breaking changes to its public interface, exceptional protocol upgrades may require structural modifications. In these cases, updated artifacts and a revised **Last updated** timestamp will deploy here simultaneously.

Devnet and Mainnet remain locked to the same current program interface version, guaranteeing that integrations successfully verified on Devnet behave identically when migrating to production.

:::danger Production Warning
The IDL and TypeScript files linked on this page are the sole authoritative assets for the active RugFreePump interface. When maintaining production integrations, verify the active **Last updated** date above—do not rely on cached or local schemas when a newer version is published.
:::
