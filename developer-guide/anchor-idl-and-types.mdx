RugFreePump publishes its **Anchor IDL** and **TypeScript types** as the machine-readable representation of its public on-chain program interface.

* **Anchor IDL:** Describes the program interface, including instructions, account layouts, arguments, events, errors, and defined types.
* **TypeScript Types:** Provides the generated TypeScript representation of the IDL for strongly typed client integrations.

RugFreePump maintains the same program interface across its supported Devnet and Mainnet deployments. The published IDL and TypeScript types therefore represent the shared protocol interface rather than separate cluster-specific variants.

## Published Artifacts

The official integration artifacts are maintained in the RugFreePump repository:

## Supported Deployments

RugFreePump maintains separate Devnet and Mainnet deployments while keeping their program interfaces synchronized.

The same current program interface is maintained across both clusters. The program ID may differ between deployments, but the published IDL and TypeScript types represent the interface maintained across both environments.

> **Deployment note:** The program ID identifies a deployment and is independent of the program interface. A change to a deployment address does not by itself require separate IDL or TypeScript artifacts when the program interface remains unchanged.

## Interface Synchronization & Versioning

The published IDL and generated TypeScript types are maintained as the current reference for the RugFreePump program interface.

**Last updated:** `September 22, 2026`

The **Last updated** date above identifies the latest published state of the IDL and TypeScript artifacts. Developers should use this date as the reference point when determining whether they are working with the current published interface.

Interface changes that require the published artifacts to be updated may include:

* **Instructions:** Changes to public instruction definitions or entry points.
* **Arguments:** Changes to instruction arguments or their types.
* **Accounts:** Changes to account structures or account relationships exposed by the interface.
* **Events:** Changes to program-emitted event definitions.
* **Errors and Types:** Changes to custom errors or defined types represented in the IDL.

RugFreePump does not intentionally introduce breaking changes to its public program interface. However, breaking changes may become necessary in exceptional circumstances. If a change affects the published IDL or TypeScript types, the updated artifacts and **Last updated** date will be published here.

Devnet and Mainnet are maintained against the same current program interface so developers can use Devnet to test integrations against the interface intended for the production deployment.

> **Important:** The IDL and TypeScript files linked on this page are the authoritative published artifacts for the current RugFreePump interface. Developers should verify the **Last updated** date on this page when maintaining an integration and should not rely on an older local copy when a newer published version is available.
