# Token and Creator Risks

RugFreePump provides infrastructure for creating and launching tokens through bonding-curve sales. The platform does not determine whether an individual token, creator, project, or external claim is legitimate or economically viable.

Participation in a sale therefore involves risks that exist independently of the RugFreePump protocol itself.

## Creator risk

Token creators control the projects they launch and may make statements about:

- Project plans
- Utility
- Roadmaps
- Partnerships
- Development
- Community activity
- Future plans

RugFreePump does not guarantee the accuracy, completeness, or future execution of those claims.

Users should independently evaluate information provided by creators.

## Creator identity

A creator address is recorded as part of the token and sale state.

However, an on-chain wallet address does not by itself establish the real-world identity of its owner.

Users should not assume that a displayed creator name, social account, website, or other identity claim has been independently verified by RugFreePump.

## Token metadata

RugFreePump creates token metadata as part of the token creation process.

The metadata includes information such as:

- Token name
- Token symbol
- Metadata URI
- Creator information

The program currently creates the metadata with the immutable metadata flag set to false for later mutation.

Users should still treat displayed metadata as project information rather than as a guarantee of legitimacy or value.

## Creator metadata verification

The creator entry associated with the token metadata is not treated as an independently verified identity.

A creator address appearing in token metadata should therefore not be interpreted as proof that the person or organization behind a project has been verified by RugFreePump.

## Token supply

The current RugFreePump token creation model uses:

- 1,000,000,000 total tokens
- 6 decimal places
- 800,000,000 tokens for the bonding-curve sale
- 200,000,000 tokens intended for liquidity

The token mint authority is revoked after the initial supply is minted.

This limits later token creation through that mint authority.

It does not protect users from changes in market value, concentration of ownership, or behavior by token holders.

## Creator ownership and concentration

Creators receive tokens through the initial creator purchase associated with pool creation.

Creators or other wallets may also hold substantial portions of a token's supply.

Concentrated ownership can create significant market risk because a large holder may be able to sell a substantial amount of tokens.

Users should inspect token distribution and wallet activity where relevant.

## Token value

A token created through RugFreePump does not have a guaranteed market value.

Token value can be affected by:

- Demand
- Community activity
- Creator behavior
- Token distribution
- Liquidity
- Market conditions
- External trading
- Project execution
- Speculation

The bonding curve does not guarantee a future market price.

## Impersonation and phishing

Attackers may impersonate legitimate RugFreePump projects, creators, communities, or administrators.

Common techniques include:

- Fake social-media accounts
- Fake Telegram groups
- Fake Discord servers
- Fake websites
- Fake token addresses
- Fake support accounts
- Malicious wallet links

Users should verify information through the official RugFreePump channels and independently confirm token addresses before interacting.

## External project claims

Statements made by token creators or community members are not automatically statements made by RugFreePump.

Users should distinguish between:

- Protocol documentation
- RugFreePump announcements
- Creator statements
- Community discussions
- Third-party claims

The existence of a token on RugFreePump does not constitute an endorsement of its creator or project.

## Creator migration authority

Under the current program design, the token creator can be an authorized executor of the normal liquidity-migration operation when all required migration conditions are satisfied.

This does not mean the creator can arbitrarily withdraw funds from the bonding curve.

Migration remains subject to the program's state checks, migration lock, configured controls, and account validation.

## Creator security

A creator's wallet can be compromised independently of RugFreePump.

A compromised creator wallet can affect the associated project and may result in:

- Unauthorized project communication
- Unauthorized transactions
- Loss of creator-controlled assets
- Malicious community activity
- Impersonation

Users should not treat creator wallet ownership as a guarantee of project security.

## User diligence

Before purchasing a token, users should consider reviewing:

- Creator wallet
- Token mint address
- Token distribution
- Project information
- Official project channels
- Community activity
- Sale progress
- Liquidity status
- Transaction history

No amount of platform-level security can remove project-specific risk.

## No investment endorsement

The presence of a token on RugFreePump does not mean that RugFreePump considers the token a safe investment, recommends the token, or guarantees the creator's conduct.

Users make their own decisions and assume the risks associated with those decisions.
