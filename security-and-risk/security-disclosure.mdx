# Security Disclosure 

RugFreePump welcomes responsible reports of potential security vulnerabilities affecting the RugFreePump protocol, application, or supporting infrastructure.

If you believe you have identified a security vulnerability, please report it privately to the RugFreePump security team before publicly disclosing the issue.

## Report a vulnerability

Security vulnerabilities can be reported to:

`security@rugfreepump.com`

Please provide enough information for the issue to be understood and reproduced.

### Include the following information

Where applicable, include:

* A clear description of the vulnerability
* The affected component or functionality
* Steps required to reproduce the issue
* Expected behavior
* Actual behavior
* Potential security impact
* Relevant transaction signatures
* Relevant public blockchain addresses
* Proof-of-concept code or demonstrations
* Any other technical information that may help with investigation

Do not include private keys, seed phrases, passwords, API credentials, or other sensitive authentication information in your report.

## Responsible testing

Security testing should be limited to systems, accounts, wallets, assets, and environments that you are authorized to test.

Please avoid actions that could cause unnecessary harm or disruption, including:

* Accessing or attempting to access another person's private credentials
* Taking or retaining assets that do not belong to you
* Modifying or destroying data unrelated to the vulnerability
* Disrupting platform availability or other users
* Conducting denial-of-service attacks
* Social engineering users or personnel
* Publicly exposing sensitive information obtained during testing

Whenever possible, demonstrate the vulnerability using the minimum level of access and activity necessary to establish its impact.

## Public disclosure

Please allow RugFreePump a reasonable opportunity to investigate a reported vulnerability before publicly disclosing technical details.

If a vulnerability involves active exploitation or presents an immediate risk to users, clearly indicate this in the report and provide any available evidence.

RugFreePump may coordinate public disclosure with the reporter when appropriate.

## Bug bounty

RugFreePump does not currently operate a formal bug bounty program.

Submitting a vulnerability report does not create an entitlement to monetary compensation or any other reward.

Any future vulnerability-reward program will be announced separately if introduced.

## Report handling

Reports submitted to `security@rugfreepump.com` are reviewed by the RugFreePump team.

Investigation and remediation may depend on the nature, severity, reproducibility, and potential impact of the reported issue.

RugFreePump does not currently provide a guaranteed response, remediation, or resolution timeline.

## Security contact

For security vulnerabilities only:

`security@rugfreepump.com`
