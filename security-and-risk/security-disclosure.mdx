# Security Disclosure

RugFreePump welcomes responsible reports from security researchers, developers, users, and community members who identify potential security vulnerabilities affecting the platform or its supporting infrastructure.

There is currently no bug bounty program.

Security reports are nevertheless encouraged and can be submitted voluntarily through the security contact below.

## Report a security vulnerability

Send security-related reports to:

`security@rugfreepump.com`

Please use this address for suspected security vulnerabilities involving RugFreePump.

Do not include private keys, seed phrases, passwords, API credentials, or other sensitive wallet credentials in a report.

## What should be reported

Examples of issues that may be appropriate to report include:

- Vulnerabilities in the RugFreePump on-chain program
- Unauthorized access to privileged protocol functionality
- Incorrect authority or permission enforcement
- Vulnerabilities affecting token or SOL handling
- Security issues in liquidity migration
- Vulnerabilities involving emergency or recovery operations
- Oracle integration vulnerabilities
- Authentication or authorization weaknesses
- Critical website vulnerabilities
- Server-side vulnerabilities
- Infrastructure compromise
- Credential exposure
- Vulnerabilities that could result in unauthorized asset movement
- Vulnerabilities that could materially compromise user security

When in doubt, report the issue and provide enough information for investigation.

## What is generally not a security vulnerability

The following are generally not security vulnerabilities by themselves:

- Token price decreases
- Normal market volatility
- Bonding-curve price movement
- Losses caused by normal trading
- Low market liquidity
- Creator disputes
- Project failure
- Disagreement with protocol design
- Feature requests
- Documentation mistakes that do not create a security impact
- Failed transactions caused by valid protocol conditions
- Ordinary Solana network fees
- General customer-support requests

These issues may still be relevant to other RugFreePump channels.

## Responsible disclosure

When reporting a vulnerability, please provide enough information to reproduce or understand the issue.

Useful information includes:

- Clear description
- Affected component
- Steps to reproduce
- Relevant transaction signatures
- Relevant public addresses
- Expected behavior
- Actual behavior
- Potential impact
- Proof of concept where appropriate

Please avoid unnecessary access to data or assets that do not belong to you.

## Safe testing

Security researchers should limit testing to environments and assets they are authorized to use.

Do not:

- Steal assets
- Access another person's wallet
- Obtain private credentials
- Destroy or alter unrelated data
- Perform destructive attacks against production infrastructure
- Disrupt users
- Conduct denial-of-service attacks
- Social-engineer users or staff

When a vulnerability can be demonstrated safely without causing real-world harm, use the safest method available.

## No bug bounty currently

RugFreePump does not currently operate a formal bug bounty program.

This means:

- No monetary reward is currently promised
- No bounty tiers currently exist
- No researcher compensation is guaranteed
- No third-party bounty platform is currently used

Future security-reward programs may be introduced as the platform matures.

Until then, researchers should not assume that a report qualifies for a financial reward.

## Report handling

Security reports sent to `security@rugfreepump.com` will be reviewed by the RugFreePump team.

The response process may depend on:

- Severity
- Reproducibility
- Potential user impact
- Whether the issue affects production systems
- Whether exploitation is active
- The complexity of remediation

No fixed response or remediation timeline is currently promised.

## Active exploitation

If you believe a vulnerability is actively being exploited, clearly identify that in the report subject and provide the strongest available evidence.

For an actively exploited issue, avoid publicly disclosing technical details before RugFreePump has had a reasonable opportunity to investigate and respond.

## Public disclosure

Researchers are encouraged to coordinate disclosure of significant vulnerabilities with RugFreePump where practical.

Public disclosure of an unresolved vulnerability can increase risk to users.

RugFreePump may publish security information when appropriate, including remediation information or general security advisories.

## Security researchers

RugFreePump appreciates responsible contributions from independent researchers and community members.

A valid security report can help identify weaknesses before they affect users, even when no bounty or monetary reward is currently offered.

## Future security program

RugFreePump plans to strengthen its security program over time.

Potential future improvements include:

- Formal third-party security audits
- Multisig authorization for critical protocol operations
- A formal vulnerability-reward program
- More structured security response procedures
- Additional security monitoring

These are future plans and should not be interpreted as currently deployed controls.

## General support

For ordinary account, platform, or usage questions, contact:

`support@rugfreepump.com`

Do not use the security address for routine support requests unless the issue involves a potential security vulnerability.

## Legal and copyright matters

Copyright infringement and other legal matters should be directed to:

`legal@rugfreepump.com`

Do not use the legal address for security vulnerability reports unless the matter is specifically legal in nature.
