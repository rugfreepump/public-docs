# Wallet and Transaction Risks

RugFreePump transactions require users to authorize actions through a Solana-compatible wallet.

The security of the wallet, the device used to access it, and the transaction approved by the user are therefore critical parts of the overall security model.

## Your wallet controls your assets

RugFreePump does not control your wallet's private keys, seed phrase, or signing credentials.

Anyone who gains unauthorized control of your wallet may be able to transfer assets independently of RugFreePump.

Never provide your:

- Seed phrase
- Private key
- Wallet password
- Hardware-wallet recovery information
- Authentication credentials

to another person or website.

RugFreePump support will never need your seed phrase or private key.

## Verify the official website

Only use the official RugFreePump domain:

`rugfreepump.com`

Attackers can create websites that imitate legitimate interfaces.

Always verify the domain before connecting a wallet or approving a transaction.

## Review every wallet prompt

A transaction displayed by the dApp should be reviewed again in the wallet before approval.

Pay particular attention to:

- Wallet address
- Token mint address
- SOL amount
- Transaction type
- Program interactions
- Expected destination accounts
- Network

Do not sign a transaction simply because the website claims it is required.

## Transaction irreversibility

Confirmed Solana transactions should be treated as irreversible unless the RugFreePump program explicitly provides a subsequent operation that changes the relevant state.

An incorrect token address, wallet address, or transaction parameter may therefore result in permanent loss.

## Phishing and impersonation

Attackers may impersonate:

- RugFreePump
- RugFreePump administrators
- Token creators
- Community moderators
- Support personnel
- Wallet providers

Do not trust unsolicited messages requesting:

- Seed phrases
- Private keys
- Wallet connections
- Emergency transfers
- "Verification" payments
- Remote-access software

Verify important information through official RugFreePump channels.

## Fake tokens and contracts

A token name or symbol is not a unique identifier.

Users should verify the token mint address before interacting with a token.

Two unrelated tokens can use similar or identical names and symbols.

## Transaction simulation and displayed information

The dApp can provide transaction previews, estimates, and interface information.

These values can change before a transaction is actually confirmed.

On-chain execution determines the final result.

Users should therefore treat interface estimates as preparation information rather than a guarantee.

## Slippage

Purchase transactions support user-configured slippage protection.

Users should choose a tolerance that reflects their intended transaction.

A tolerance that is too strict can cause transactions to fail.

A tolerance that is too high can permit a larger state change than the user intended.

Slippage protection does not guarantee future token price stability.

## Wallet balance

Users should maintain enough SOL for:

- The intended protocol transaction
- Applicable protocol amounts
- Solana network fees
- Any required priority fee
- Required account creation or rent-related costs where applicable

A transaction can fail when the wallet does not contain sufficient funds.

## Network and RPC conditions

Wallets and dApps generally depend on RPC infrastructure to prepare and submit Solana transactions.

RPC outages, latency, or inconsistent network conditions can affect:

- Displayed balances
- Transaction preparation
- Transaction submission
- Confirmation
- Displayed transaction status

Users should verify important transactions independently through a Solana explorer.

## Wallet connection security

Only connect a wallet to websites you trust.

Disconnecting a wallet from a website does not necessarily undo transactions that have already been signed or state changes that have already occurred.

Users should understand what they are approving before signing.

## Device and browser security

Wallet security also depends on the device used to access it.

Users should maintain appropriate security practices, including:

- Current operating-system updates
- Current browser versions
- Trusted wallet extensions
- Strong device authentication
- Malware protection
- Avoiding unknown software

A compromised device can undermine otherwise secure wallet practices.

## User responsibility

Users are responsible for the transactions they authorize.

Before signing, users should verify:

1. The official website
2. The connected wallet
3. The token mint
4. The transaction amount
5. The transaction type
6. The expected result
7. The network
8. The wallet's final transaction prompt

## Security incidents

If you believe your wallet has been compromised, do not continue signing transactions from the affected wallet.

Move remaining assets to a secure wallet when appropriate and investigate the compromise independently.

For a suspected RugFreePump security vulnerability, contact:

`security@rugfreepump.com`

Do not send seed phrases or private keys with a security report.
