---
title: Wallet and Transaction Risks
description: Protect your wallet and understand the risks associated with signing RugFreePump transactions.
---

A user's wallet is the final authorization layer for transactions submitted through RugFreePump.

The security of a transaction therefore depends not only on the RugFreePump program, but also on the user's wallet, device, browser, network connection, and ability to identify the transaction being authorized.

Web3 wallets manage private keys and sign transactions that can move digital assets. Wallet security and transaction-signing security are therefore critical parts of the overall security model.

## Use the official RugFreePump domain

Always verify that you are using the official RugFreePump website before connecting a wallet or signing a transaction.

Do not assume that a search result, social-media link, advertisement, message, or support account is legitimate.

Look-alike domains can be designed to resemble the official site.

## Never share wallet credentials

RugFreePump will never legitimately require a user to provide:

- Seed phrase.
- Private key.
- Wallet recovery phrase.
- Hardware-wallet recovery information.
- Wallet password.
- Secret signing material.

Anyone requesting these credentials while claiming to represent RugFreePump should be treated as suspicious.

## Review every transaction

Before approving a transaction, users should review the transaction presented by their wallet.

At minimum, verify:

- The intended action.
- The amount of SOL being spent.
- The token mint or destination where applicable.
- Applicable fees.
- The connected network.
- Any other transaction details displayed by the wallet.

Users should not approve a transaction solely because the dApp interface says that it is safe.

## Blind signing risk

A wallet may display transaction information differently depending on the wallet and transaction type.

If the wallet cannot clearly communicate what is being signed, users should avoid approving the transaction until they can independently verify its contents.

The difference between what a user believes they are signing and what the blockchain actually executes is a recognized Web3 security risk.

## Phishing and impersonation

Attackers may impersonate:

- RugFreePump.
- Token creators.
- Community moderators.
- Support personnel.
- Wallet providers.
- Security researchers.

Common attack methods include:

- Fake websites.
- Look-alike domains.
- Fake social-media accounts.
- Fake support messages.
- Malicious browser extensions.
- QR-code phishing.
- Malicious transaction links.

Users should independently verify security-sensitive requests through an established official channel.

## Device and browser security

A compromised computer can undermine wallet security even when the blockchain program itself is functioning correctly.

Users should:

- Keep their operating system updated.
- Keep wallet software updated.
- Avoid installing unknown browser extensions.
- Avoid downloading software from unsolicited links.
- Use reputable security software.
- Avoid signing transactions from compromised or shared devices.

## Wallet connection risk

Connecting a wallet to a dApp does not by itself mean that the dApp can freely spend all assets in the wallet.

However, users should still understand what they are authorizing when signing transactions.

A malicious site can attempt to use wallet interactions to trick a user into approving an unintended transaction.

## Transaction irreversibility

Blockchain transactions should be treated as potentially irreversible.

If a user:

- Sends assets to the wrong address.
- Approves an unintended transaction.
- Signs a malicious transaction.
- Loses access to their wallet.

RugFreePump may not be able to reverse the resulting blockchain state.

## Network and RPC conditions

A transaction can fail, be delayed, or become outdated because of network or RPC conditions.

Users should inspect the actual transaction status rather than assuming that a wallet notification alone represents final on-chain confirmation.

## User responsibilities

Users are responsible for:

- Protecting wallet credentials.
- Verifying the official RugFreePump domain.
- Reviewing transactions before signing.
- Confirming token mint addresses.
- Checking applicable fees.
- Understanding the economic risks of the transaction.
- Maintaining control of their wallet device and credentials.

## Security incident response

If a user believes they have signed a malicious transaction or compromised their wallet, they should immediately follow their wallet provider's security procedures.

RugFreePump support cannot recover private keys or reverse arbitrary Solana transactions.

For suspected vulnerabilities in RugFreePump itself, use the official security disclosure process.

> **Important:** The strongest protection against transaction-signing attacks is verifying what is being signed before authorization. Users should never sign a transaction they do not understand or cannot independently verify.
