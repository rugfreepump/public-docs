The following are the current fees charged or allocated by the RugFreePump protocol.

| Fee Type | Current Fee | Updatable Range |
| --- | ---: | ---: |
| **Bonding Curve Escrow Creation Fee**<br/>Fee charged when creating a bonding curve sale. | **$5.00** | **$0.00–$10.00** |
| **Buy Fee**<br/>Fee applied to each bonding curve token purchase. | **1%** | **0.5%–1%** |
| **Bonding Curve Escrow Completion Fee**<br/>Fee deducted from completed sale funds during liquidity migration or recovery. | **3%** | **2%–3%** |
| **Creator Incentive**<br/>A portion of completed sale funds allocated to eligible token creators. | **1%** | **0.1%–1%** |
| **DEX Pool Creation Fee**<br/>SOL reserved from completed sale funds for DEX pool creation and related migration costs. | **0.5 SOL** | **0.25–1 SOL** |

<Callout type="info" title="Fee Updates">
Protocol fees may be updated over time by the authorized protocol authority. The current fee and updatable range shown above reflect the protocol's current configuration and on-chain limits.
</Callout>
