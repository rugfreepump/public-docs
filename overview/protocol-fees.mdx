title: "Protocol Fees"
description: "Reference the current RugFreePump protocol fees and rates."
---

The following are the current fees and rates applied by the RugFreePump protocol.

| Operation | Fee / Rate | Paid By |
| --- | ---: | --- |
| Create a bonding curve sale | **$5 USD equivalent in SOL** | Creator |
| Buy bonding curve sale tokens | **1%** | Buyer |
| Migrate raised liquidity | **3% of raised funds** | Sale funds |
| Creator Incentive | **0.1%–1%** | Sale funds, when enabled |
| Raydium CPI-related costs and required account rent | **0.5 SOL** | Sale funds |
| Solana network transaction fees | **Variable** | Transaction sender |

<Callout type="info" title="Fee Updates">
Protocol fees and rates may be updated over time. The amounts shown on this page represent the current protocol configuration.
</Callout>
