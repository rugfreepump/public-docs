# Welcome To RugFreePump

RugFreePump is a Solana token launchpad built around a high-conviction approach to token launches. Instead of opening every newly created token to an unrestricted market from the start, RugFreePump uses a structured bonding curve sale with protocol-enforced rules that define how a launch progresses from creation to completion.

The protocol is designed to reduce reliance on trust during the most critical stage of a token launch. Core sale rules, pricing, fund flows, and state transitions are governed by on-chain program logic, giving creators and buyers a clearly defined framework for participating in a launch.

These docs explain how RugFreePump works, what makes its launch model different, how to create and participate in sales, how the protocol operates on-chain, and how developers can build directly on top of the platform.
