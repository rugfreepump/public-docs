# Welcome To RugFreePump

RugFreePump is a Solana-based token launchpad that uses bonding curve sales to provide a transparent and structured way to launch and participate in token sales.

These docs explain how RugFreePump works, how to create and participate in sales, how the protocol operates on-chain, and how developers can integrate with the platform.
