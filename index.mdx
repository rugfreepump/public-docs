These docs are designed to help you **understand, use, research, verify, integrate with, and build on RugFreePump**, a Solana-native, high-conviction crowdfunded launchpad built around structured bonding curve fundraising and protocol-defined sale outcomes.

Whether you are participating in a token sale, launching a project, exploring the protocol, developing an integration, or reviewing its on-chain execution, this documentation helps you find the resources relevant to your goals.

## Who Is This Documentation For?

RugFreePump documentation serves participants, creators, developers, researchers, and reviewers with different objectives and levels of technical experience.

### Token Buyers

Learn how to prepare a Solana wallet, participate in bonding curve sales, understand purchased token claiming conditions, manage eligible withdrawals, and make informed decisions about participation.

### Token Creators

Learn how to create a coin, configure its information, select a token sale model, launch a bonding curve sale, and complete the liquidity migration process following a successful sale.

### Developers & Integrators

Explore the public Solana on-chain program, supported integration methods, Anchor IDL and generated types, and the technical boundaries of building applications that interact with RugFreePump.

### Researchers & Analysts

Examine the fundraising model, bonding curve mechanics, token sale models, protocol fees, sale lifecycle, liquidity migration, and economic principles underlying RugFreePump.

### Auditors & Technical Reviewers

Explore on-chain execution verification, protocol security, administrative authority, upgradeability, technical limitations, and responsible vulnerability disclosure.

### Ecosystem Participants

Discover the Reward Program, official announcements, frequently asked questions, safety resources, and legal policies relevant to the broader RugFreePump ecosystem.

## How to Use These Docs

Choose the documentation path that best matches what you want to accomplish, understand, or verify.

### New to RugFreePump?

Start with **Overview** to become familiar with the Platform's purpose, fundraising approach, and sale lifecycle.

Read [Overview](/overview/overview) for the fundamental concepts, [Token Sale Models](/overview/token-sale-models) for the differences between Token Unlocked (TU) and Token Locked (TL) sales, and [Protocol Fees](/overview/protocol-fees) for current charges and their authorized update ranges.

### Want to Participate in a Launch?

Start with **User Guides** to prepare for your first token purchase.

Follow [Getting Started](/user-guides/getting-started) to prepare and connect a supported Solana wallet. Review [Trust & Safety](/user-guides/trust-and-safety) for wallet protection and [RugFreePump Consent](/user-guides/rugfreepump-consent) for the Platform's consent requirements.

Continue with [Buying Bonding Curve Sale Tokens](/user-guides/for-token-buyers/buying-bonding-curve-sale-tokens) for the purchase process, or visit the [FAQ](/user-guides/faq) for answers to common questions.

### Want to Launch a Token?

Start with **User Guides → For Token Creators**.

Follow [Creating a Bonding Curve Sale](/user-guides/for-token-creators/creating-a-bonding-curve-sale) for coin creation, sale configuration, token sale model selection, and launch requirements.

Then explore [Migrating Raised Liquidity](/user-guides/for-token-creators/migrating-raised-liquidity) to understand the process that follows successful fundraising, including liquidity migration to Raydium CPMM.

### Want to Manage Your Contributions?

Start with **User Guides → For Token Buyers**.

Review [Buying Bonding Curve Sale Tokens](/user-guides/for-token-buyers/buying-bonding-curve-sale-tokens) for information about purchases and recorded token allocations.

Follow [Claiming Purchased Tokens](/user-guides/for-token-buyers/claiming-purchased-tokens) to understand claiming eligibility and the different conditions under TU and TL sales.

For expired or eligible canceled sales, see [Withdrawing Contributed SOL](/user-guides/for-token-buyers/withdrawing-contributed-sol) for withdrawal requirements and instructions.

### Want to Understand the Protocol?

Start with **Overview** to explore RugFreePump's design and operating principles.

Read [Overview](/overview/overview) for the fundraising model and sale progression, then continue with [Token Sale Models](/overview/token-sale-models) and [Protocol Fees](/overview/protocol-fees) for token distribution and fee structures.

For information about the verification of protocol operations, explore [Proof of Execution](/on-chain-program/proof-of-execution).

### Want to Build on RugFreePump?

Start with the **Developer Guide**.

Read [Building on RugFreePump](/developer-guide/building-on-rugfreepump) for the available development approach and integration considerations.

Explore [Buy](/developer-guide/on-chain-integration/buy) for the documented on-chain purchase integration, and [Anchor IDL & Types](/developer-guide/anchor-idl-and-types) for program interface resources.

Before building, review [Developer Limitations](/developer-guide/developer-limitations) to understand the supported integration scope and existing boundaries.

### Want to Audit or Verify the Protocol?

Start with **On-Chain Program**.

Read [Proof of Execution](/on-chain-program/proof-of-execution) to understand how protocol operations and execution outcomes can be independently examined through Solana's public blockchain.

For supporting technical information, explore [Building on RugFreePump](/developer-guide/building-on-rugfreepump) and [Anchor IDL & Types](/developer-guide/anchor-idl-and-types).

Review [Security](/security-and-risk/security) and [Risks](/security-and-risk/risks) for protocol authority, security considerations, and remaining risks.

### Want to Understand Security and Risk?

Start with **Security & Risks**.

Read [Security](/security-and-risk/security) for the Platform's security approach and administrative controls, followed by [Risks](/security-and-risk/risks) for technical, financial, and operational risk considerations.

If you identify a potential vulnerability, follow the [Security Disclosure](/security-and-risk/security-disclosure) process.

For practical wallet and transaction protection, also review [Trust & Safety](/user-guides/trust-and-safety).

### Want to Understand the Reward Program?

Start with **Reward Program**.

Read [Reward Program](/reward-program/reward-program) for participation requirements, reward periods, buyer and creator rankings, eligibility, calculations, and distribution procedures.

For official Reward Program developments and published results, visit [Announcements](/announcements/announcements).

### Want to Review Legal and Compliance Information?

Start with **Legal & Compliance**.

Review the [Terms of Service](/legal-and-compliance/terms-of-service), [Privacy Policy](/legal-and-compliance/privacy-policy), and [Risk Disclosure](/legal-and-compliance/risk-disclosure) for Platform conditions, information handling, user responsibilities, and important risks.

For intellectual property matters, see the [Copyright Policy](/legal-and-compliance/copyright-policy) and [Trademark Guidelines](/legal-and-compliance/trademark-guidelines).

### Want to Follow Platform Updates?

Start with **Announcements**.

Visit [Announcements](/announcements/announcements) for official Platform notices, Reward Program results, feature releases, maintenance information, bug fixes, and other important updates.

Publications are organized with the newest announcements first, allowing you to follow recent developments and revisit earlier notices.
