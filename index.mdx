These docs are designed to help you understand, use, research, verify, integrate with, and build on RugFreePump. Whether you are participating in a token sale, launching a project, developing an integration, reviewing the on-chain program, or researching how the protocol works, you can find the information relevant to you here.

## Who Is This Documentation For?

RugFreePump documentation is built for different types of users and participants across the ecosystem.

### Token Buyers

Learn how to get started, connect and fund a wallet, participate in bonding curve sales, understand withdrawals, and navigate the platform safely.

### Token Creators

Learn how to create a token, launch a bonding curve sale, understand the fundraising process, and migrate successfully completed liquidity.

### Developers & Integrators

Build applications, bots, analytics tools, trading interfaces, and other integrations using RugFreePump's on-chain program, APIs, generated types, and real-time infrastructure.

### Researchers & Analysts

Explore the protocol's mechanics, tokenomics, bonding curve, oracle pricing, fees, sale lifecycle, and other technical and economic concepts.

### Auditors & Technical Reviewers

Review the RugFreePump on-chain program, account structures, instruction design, PDA derivation, proof of execution, and security model.

### Ecosystem Participants

Understand the reward program, platform updates, security considerations, legal policies, and other aspects of the RugFreePump ecosystem.

## How to Use These Docs

If you are new to RugFreePump, start with the **Overview** to understand the platform and its launch model.

If you want to participate in a sale or launch a project, go to **User Guides**.

If you want to understand how the protocol works, explore **Core Mechanics** and the **On-Chain Program**.

If you are building an application or integration on top of RugfreePump, start with the **Developer Guide**.

If you are reviewing security, risks, or protocol boundaries, see **Security & Risk**.
