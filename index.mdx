These docs are designed to help you **understand, use, research, verify, integrate with, and build on RugFreePump**. Whether you are participating in a bonding curve sale, launching a project, developing an integration, reviewing the on-chain program, or researching the protocol, you can find the resources relevant to your role and objective.

## Who Is This Documentation For?

RugFreePump documentation is organized around the different participants, builders, researchers, and reviewers who interact with the ecosystem.

### Token Buyers

Learn how to get started, choose, create, and fund a wallet, participate in bonding curve sales, understand eligible withdrawals, and use the platform safely.

### Token Creators

Learn how to create a token, launch a bonding curve sale, manage the fundraising process, and migrate liquidity after a successful sale.

### Developers & Integrators

Build applications, bots, analytics tools, trading interfaces, and other integrations using RugFreePump's public on-chain program, APIs, generated types, and real-time infrastructure.

### Researchers & Analysts

Explore tokenomics, bonding curve pricing, oracle pricing, protocol fees, sale lifecycle, and the technical and economic principles behind RugFreePump.

### Auditors & Technical Reviewers

Review the on-chain program, public instructions, account structures, Program Derived Address (PDA) derivation, transaction requirements, proof of execution, and security model.

### Ecosystem Participants

Explore the reward program, platform announcements, security considerations, legal policies, and other resources covering the broader RugFreePump ecosystem.

## How to Use These Docs

Choose the path that best matches what you are trying to accomplish.

### New to RugFreePump

Start with the **Overview** section to understand the platform and its launch model.

Begin with [What is RugFreePump](/overview/what-is-rugfreepump), then follow [How RugFreePump Works](/overview/how-rugfreepump-works) to understand how a token sale progresses from creation through its possible outcomes.

### Want to Participate in a Launch

Start with the **User Guides → First Steps** section.

Begin with [Getting Started](/user-guides/first-steps/getting-started), then work through [What You Need](/user-guides/first-steps/what-you-need), [Choosing a Wallet](/user-guides/first-steps/choosing-a-wallet), [Creating a Wallet](/user-guides/first-steps/creating-a-wallet), and [Funding a Wallet](/user-guides/first-steps/funding-a-wallet).

When you are ready to participate, continue with [Your First Purchase](/user-guides/first-steps/your-first-purchase).

For practical guidance on participating safely, see [User Guides → Trust & Safety](/user-guides/trust-and-safety).

### Want to Launch a Token

Start with **User Guides → For Token Creators**.

Follow [Creating a Bonding Curve Sale](/user-guides/for-token-creators/creating-a-bonding-curve-sale) to create and launch a sale.

After a sale successfully completes, continue with [Migrating Raised Liquidity](/user-guides/for-token-creators/migrating-raised-liquidity) to understand the liquidity migration process.

### Want to Manage Your Contributions

Start with **User Guides → For Token Buyers**.

Learn the purchase process in [Buying Bonding Curve Sale Tokens](/user-guides/for-token-buyers/buying-bonding-curve-sale-tokens).

If a sale expires or is canceled and your contribution becomes eligible for withdrawal, follow [Withdrawing Contributed SOL](/user-guides/for-token-buyers/withdrawing-contributed-sol).

### Want to Understand the Protocol

Start with the **Core Mechanics** section.

Begin with [Tokenomics](/core-mechanics/tokenomics) and then explore [Token Metadata](/core-mechanics/token-metadata), [Slippage & Priority](/core-mechanics/slippage-and-priority), [Oracle Price](/core-mechanics/oracle-price), [Bonding Curve](/core-mechanics/bonding-curve), [Protocol Fees](/core-mechanics/protocol-fees), and [Sale Lifecycle](/core-mechanics/sale-lifecycle).

For a deeper look at the program that enforces these rules, continue to **On-Chain Program** with the [On-Chain Program Overview](/on-chain-program/overview) and [Proof of Execution](/on-chain-program/proof-of-execution).

### Want to Build on RugFreePump

Start with the **Developer Guide**.

Begin with [Building on RugFreePump](/developer-guide/building-on-rugfreepump) for the overall integration approach.

For direct interaction with the Solana program, continue to **Developer Guide → On-Chain Program**, starting with [Program ID & Network](/developer-guide/on-chain-program/program-id-and-network) and [Public Instructions](/developer-guide/on-chain-program/public-instructions), followed by [Account Structures](/developer-guide/on-chain-program/accounts-and-account-structures), [PDA Derivation & Seeds](/developer-guide/on-chain-program/pda-derivation-and-seeds), [Instruction Arguments](/developer-guide/on-chain-program/instruction-arguments), [Transaction Requirements](/developer-guide/on-chain-program/transaction-requirements), [Anchor IDL](/developer-guide/on-chain-program/anchor-idl), and [Generated Types](/developer-guide/on-chain-program/generated-types).

### Want to Integrate Through APIs or WebSockets

Start with **Developer Guide → API Integration**.

Begin with the [API Integration Overview](/developer-guide/api-integration/overview) to understand the integration model and request/response structure.

For programmatic protocol operations, follow the dedicated guides for [Create Sale](/developer-guide/api-integration/create-sale), [Buy](/developer-guide/api-integration/buy), [Withdraw](/developer-guide/api-integration/withdraw), and [Migrate Liquidity](/developer-guide/api-integration/migrate-liquidity).

Then review [Rate Limits & Restrictions](/developer-guide/api-integration/rate-limits-and-restrictions), [Errors](/developer-guide/api-integration/errors), and [Real-Time WebSocket](/developer-guide/api-integration/realtime-websocket) for production integrations.

### Want to Audit or Verify the Protocol

Start with **On-Chain Program**.

Read the [On-Chain Program Overview](/on-chain-program/overview) to understand the program's role, then use [Proof of Execution](/on-chain-program/proof-of-execution) to understand how important protocol behavior can be verified from on-chain execution.

For implementation-level review, continue through **Developer Guide → On-Chain Program**, including [Public Instructions](/developer-guide/on-chain-program/public-instructions), [Account Structures](/developer-guide/on-chain-program/accounts-and-account-structures), and [PDA Derivation & Seeds](/developer-guide/on-chain-program/pda-derivation-and-seeds).

### Want to Understand Security and Risk

Start with the **Security & Risk** section.

Begin with the [Security Model](/security-and-risk/security-model), then review the risk areas most relevant to your research, including [Smart Contract Risks](/security-and-risk/smart-contract-risks), [Oracle Risks](/security-and-risk/oracle-risks), [Launch & Sale Risks](/security-and-risk/launch-and-sale-risks), and [Liquidity & Migration Risks](/security-and-risk/liquidity-and-migration-risks).

For participant-specific guidance, see [User Responsibilities](/security-and-risk/user-responsibilities).

If you discover a potential vulnerability, follow the [Security Disclosure](/security-and-risk/security-disclosure) process.

### Want to Understand the Reward Program

Start with **Reward Program**.

Begin with the [Reward Program Overview](/reward-program/overview) to understand the program, then explore [How Rewards Are Earned](/reward-program/how-rewards-are-earned), [Reward Periods & Rankings](/reward-program/reward-periods-and-rankings), [Reward Calculation](/reward-program/reward-calculation), and [Reward Distribution](/reward-program/reward-distribution) for the complete reward lifecycle.

### Want to Review Legal and Compliance Information

Start with **Legal & Compliance**.

Review the [Terms of Service](/legal-and-compliance/terms-of-service), [Privacy Policy](/legal-and-compliance/privacy-policy), [Risk Disclosure](/legal-and-compliance/risk-disclosure), [DMCA Policy](/legal-and-compliance/dmca-policy), and [Trademark Guidelines](/legal-and-compliance/trademark-guidelines).

### Want to Follow Platform Updates

Start with **Announcements**.

The [Updates & Changelog](/announcements/updates-and-changelog) page contains platform updates, protocol changes, infrastructure improvements, releases, and documentation changes.

## Find What You Need
