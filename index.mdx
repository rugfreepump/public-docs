Welcome to the official **RugFreePump Documentation**.

These docs are designed to help you **understand, use, research, verify, and build on RugFreePump**. Whether you are participating in a bonding curve sale, launching a token, exploring the Reward Program, integrating with the Solana program, or reviewing security and risk considerations, you can find the information relevant to your goals.

## Who Is This Documentation For?

RugFreePump documentation is organized around the different participants, developers, researchers, and reviewers who interact with the Platform.

### Token Buyers

Learn how to connect a wallet, participate in bonding curve sales, understand the differences between Token Unlocked (TU) and Token Locked (TL) sale models, claim purchased tokens, withdraw eligible SOL contributions, and use the Platform safely.

### Token Creators

Learn how to create a token, launch a bonding curve sale, understand fundraising requirements, and migrate raised liquidity to Raydium CPMM following a successful sale.

### Developers & Integrators

Explore the RugFreePump on-chain program, Anchor IDL, generated types, supported integration methods, and the limitations developers should consider when building external applications or services.

### Researchers & Technical Reviewers

Explore token supply allocation, bonding curve fundraising, protocol fees, token sale models, transaction verification, security considerations, and the on-chain mechanisms behind RugFreePump.

### Reward Program Participants

Understand how the Buyers and Creators Reward Pools operate, how qualifying activity is evaluated, how rankings are determined, and how rewards are distributed.

### Ecosystem Participants

Follow official announcements, review Platform policies, understand security and financial risks, and explore resources covering the broader RugFreePump ecosystem.

## How to Use These Docs

Choose the path that best matches what you are trying to accomplish.

### New to RugFreePump?

Start with the **Overview** section.

Read [Overview](/overview/overview) to understand RugFreePump, its bonding curve fundraising mechanism, token supply allocation, and the different outcomes of a token sale.

Continue with [Token Sale Models](/overview/token-sale-models) to understand the differences between TU and TL sales, including how purchased tokens become claimable following successful liquidity migration.

For information about Platform charges, see [Protocol Fees](/overview/protocol-fees).

### Want to Participate in a Token Sale?

Start with **User Guides**.

Follow [Getting Started](/user-guides/getting-started) to understand the requirements for using RugFreePump, connecting a supported wallet, and preparing to participate.

Before making a purchase, review [Trust & Safety](/user-guides/trust-and-safety) for practical guidance on wallet security, transaction verification, and participation risks.

Then continue with [Buying Bonding Curve Sale Tokens](/user-guides/for-token-buyers/buying-bonding-curve-sale-tokens) for a detailed explanation of the purchase process.

### Want to Launch a Token?

Start with **User Guides → For Token Creators**.

Follow [Creating a Bonding Curve Sale](/user-guides/for-token-creators/creating-a-bonding-curve-sale) to understand token creation, sale configuration, the fundraising mechanism, and the available token sale models.

When a sale reaches its fundraising hard cap, continue with [Migrating Raised Liquidity](/user-guides/for-token-creators/migrating-raised-liquidity) to understand the Raydium CPMM liquidity migration process and the burning of liquidity-provider tokens.

### Want to Claim Purchased Tokens?

Start with **User Guides → For Token Buyers**.

Read [Claiming Purchased Tokens](/user-guides/for-token-buyers/claiming-purchased-tokens) to understand when purchased tokens become claimable following successful liquidity migration.

The guide explains how claiming differs between TU and TL sales, including the gradual unlock schedule applicable to TL allocations.

### Want to Withdraw Contributed SOL?

Start with **User Guides → For Token Buyers**.

Read [Withdrawing Contributed SOL](/user-guides/for-token-buyers/withdrawing-contributed-sol) to understand withdrawal eligibility, supported sale outcomes, and the transaction process for recovering eligible contributions.

Withdrawals are not ordinary bonding curve sell transactions and are available only under the applicable protocol conditions.

### Want to Understand the Reward Program?

Start with **Reward Program**.

Read [Reward Program](/reward-program/reward-program) to understand the Buyers and Creators Reward Pools, qualifying activity, reward periods, leaderboard rankings, allocation calculations, and distribution procedures.

The guide also explains important eligibility requirements and the limitations of estimated rewards.

### Want to Understand the On-Chain Program?

Start with **On-Chain Program**.

Read [Proof of Execution](/on-chain-program/proof-of-execution) to understand how RugFreePump's important protocol operations can be verified through Solana transaction records and on-chain account data.

For implementation details and integration considerations, continue with the [Developer Guide](/developer-guide/building-on-rugfreepump).

### Want to Build on RugFreePump?

Start with **Developer Guide**.

Read [Building on RugFreePump](/developer-guide/building-on-rugfreepump) to understand the supported integration approaches and the technical requirements for interacting with RugFreePump.

Continue with [On-Chain Integration — Buy](/developer-guide/on-chain-integration/buy) for the documented on-chain purchase integration flow.

Review [Anchor IDL & Types](/developer-guide/anchor-idl-and-types) for information about the program interface and generated types.

Before developing an integration, read [Developer Limitations](/developer-guide/developer-limitations) to understand relevant restrictions, responsibilities, and unsupported capabilities.

### Want to Understand Security and Risk?

Start with **Security & Risks**.

Read [Security](/security-and-risk/security) to understand the Platform's security architecture, on-chain enforcement mechanisms, administrative controls, and trust considerations.

Continue with [Risks](/security-and-risk/risks) for a broader explanation of the technical, financial, operational, and participation risks associated with RugFreePump.

If you discover a potential vulnerability, follow the reporting guidance in [Security Disclosure](/security-and-risk/security-disclosure).

For practical wallet and transaction safety guidance, also review [Trust & Safety](/user-guides/trust-and-safety).

### Want to Review Legal and Compliance Information?

Start with **Legal & Compliance**.

Review the [Terms of Service](/legal-and-compliance/terms-of-service), [Privacy Policy](/legal-and-compliance/privacy-policy), and [Risk Disclosure](/legal-and-compliance/risk-disclosure) to understand the applicable Platform terms, information practices, and important risk disclosures.

For intellectual property and content-related matters, see the [Copyright Policy](/legal-and-compliance/copyright-policy) and [Trademark Guidelines](/legal-and-compliance/trademark-guidelines).

### Want to Follow Platform Announcements?

Start with **Announcements**.

Visit [Announcements](/announcements/announcements) to read official Platform launch announcements, Reward Program updates and results, new feature releases, maintenance notices, bug fixes, and other important developments.

Announcements are published in reverse chronological order, with the newest entries appearing first. Each announcement has its own reference number and a direct link to its full content.

### Looking for Answers to Common Questions?

Visit the [Frequently Asked Questions](/user-guides/faq) page.

The FAQ covers common questions about wallets, authentication, bonding curve sales, token creation, TU and TL sale models, claiming, withdrawals, liquidity migration, protocol fees, rewards, and security.

## Find What You Need

Use the documentation search bar to find a specific page, feature, protocol concept, instruction, or technical term.

If you are exploring RugFreePump for the first time, begin with the [Overview](/overview/overview) or [Getting Started](/user-guides/getting-started) guides.

For questions about a particular Platform operation, navigate directly to the relevant User Guide or consult the [FAQ](/user-guides/faq).
