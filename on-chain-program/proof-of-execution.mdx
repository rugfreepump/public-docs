# Proof of Execution

RugFreePump operates entirely through an autonomous on-chain program deployed on the Solana network. This page provides a transparent, verifiable record of the program’s lifecycle—from compilation and deployment to real-time user transactions on Solana Devnet.

For participants, the critical difference lies between an application **claiming** an operation happens securely on-chain and being able to **verify the transaction yourself** using an independent blockchain explorer.

## Protocol Infrastructure

The RugFreePump on-chain program contains the core rules required to launch tokens and manage automated bonding-curve pools. 

To guarantee platform security and stability, the program utilizes **53 total instructions**:
- **49 Administrative Instructions:** Internal entry points reserved strictly for authorized protocol setup, emergency circuit breakers, and governance parameter calibration.
- **4 Public Instructions:** Open-access entry points that power the core user-facing token lifecycle.

### The Token Lifecycle
The four public instructions govern how tokens move through the platform:

| Instruction | Purpose | Impact on Funds |
| :--- | :--- | :--- |
| **`create_pool`** | Launches a new token and deploys its dedicated bonding-curve pool. | Establishes the initial token supply and pricing curve. |
| **`buy`** | Purchases tokens directly from the active bonding curve. | Deposits SOL into the pool reserve and issues tokens to the buyer. |
| **`withdraw`** | Withdraws funds according to the protocol's predefined pooling rules. | Safely extracts liquidity based on verified curve milestones. |
| **`migrate_liquidity`** | Permanently moves liquidity once the bonding curve is 100% complete. | Locks accumulated liquidity into a secure Raydium CPMM pool. |
