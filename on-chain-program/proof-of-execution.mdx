# Proof of Execution

RugFreePump's core token lifecycle is executed by a dedicated on-chain program on Solana.

This page shows the program from compilation through deployment and initialization, followed by the execution of every public instruction used by the RugFreePump application.

The resulting Solana transactions are publicly accessible, allowing users to independently verify that the operations initiated through the RugFreePump interface are processed by the deployed on-chain program.

**Compile → Deploy → Initialize → Create Pool → Buy → Withdraw → Migrate Liquidity**

> **Network:** Solana Devnet
>
> **Program ID:** `9hpBPEiywp7FPAq5uP253eAZzdJ1Cpd36L5RAYuc9xSw`

## The RugFreePump On-Chain Program

The RugFreePump program contains the on-chain logic responsible for creating and operating bonding-curve pools.

The deployed program contains **53 instructions** in total:

* **49 administrative instructions** — restricted to authorized platform administration.
* **4 public instructions** — used by users through the RugFreePump application.

The four public instructions define the user-facing token lifecycle:

| Instruction         | Purpose                                                                 |
| ------------------- | ----------------------------------------------------------------------- |
| `create_pool`       | Creates a new RugFreePump token and its bonding-curve pool.             |
| `buy`               | Purchases tokens from an active bonding-curve pool.                     |
| `withdraw`          | Withdraws funds according to the bonding-curve pool's withdrawal rules. |
| `migrate_liquidity` | Migrates completed bonding-curve liquidity to a Raydium CPMM pool.      |

The administrative instructions are separate from the public user execution flow demonstrated on this page.

# Verify the Program on Solana

RugFreePump does not require users to rely solely on what the application displays.

The program has a fixed public address on Solana, and operations performed through it produce publicly inspectable transactions. This allows the relationship between the RugFreePump application and its on-chain program to be verified independently.

For each operation demonstrated above, the verification path is:

```text
RugFreePump Application
        ↓
RugFreePump On-Chain Program
        ↓
Solana Devnet
        ↓
Transaction Signature
        ↓
Solscan
```

A user can take the Program ID or any transaction signature published on this page and inspect the corresponding Solana record independently.

This is particularly important when interacting with a blockchain application: the application provides the interface, while the blockchain provides the public record of the transaction that was actually submitted and confirmed.

# About the Verification Environment

The demonstrations on this page were performed on **Solana Devnet**.

Devnet provides a public Solana environment for demonstrating the deployed program and its public operations without requiring real funds.

The Program ID and transaction signatures shown above correspond to publicly accessible Devnet records and can be independently inspected through Solscan.

This page demonstrates the deployment and execution of the RugFreePump program. It is not an independent security audit or formal verification of the program.

For production mainnet interactions, users should verify that the Program ID presented by the official RugFreePump application matches the officially published production address and review the transaction details presented by their wallet before approving a transaction.

The goal is straightforward: make the on-chain component of RugFreePump visible and independently verifiable, so users can inspect what the program is and what it actually executes rather than relying solely on application-level claims.
