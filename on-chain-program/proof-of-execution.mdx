# Proof of Execution

RugFreePump is powered by an on-chain program deployed on Solana. This page provides a transparent record of that program being compiled, deployed, initialized, and exercised through the RugFreePump application.

For users, the important distinction is between an application simply claiming that an operation happens on-chain and being able to **inspect the resulting transactions for yourself**.

The execution record presented here follows the complete path from the program source to publicly verifiable on-chain activity:

**Compile → Deploy → Initialize → Create Pool → Buy → Withdraw → Migrate Liquidity**

The four public instructions are demonstrated through the RugFreePump application, with each execution producing a transaction that can be independently inspected on Solana Devnet through Solscan.

> **Network:** Solana Devnet
>
> **Program ID:** `9hpBPEiywp7FPAq5uP253eAZzdJ1Cpd36L5RAYuc9xSw`


## On-Chain Program

The RugFreePump on-chain program provides the core functionality required to create and operate RugFreePump bonding-curve pools.

The deployed program contains **53 instructions** in total:

* **49 administrative instructions** — restricted to authorized platform administration.
* **4 public instructions** — available for user-facing execution through the RugFreePump application.

The four public instructions form the core user-facing token lifecycle:

| Instruction         | Purpose                                                                 |
| ------------------- | ----------------------------------------------------------------------- |
| `create_pool`       | Creates a new RugFreePump token and its bonding-curve pool.             |
| `buy`               | Purchases tokens from an active bonding-curve pool.                     |
| `withdraw`          | Withdraws funds according to the bonding-curve pool's withdrawal rules. |
| `migrate_liquidity` | Migrates completed bonding-curve liquidity to a Raydium CPMM pool.      |

The administrative instructions are not part of the public execution flow demonstrated on this page.

# Independent Verification

The purpose of this page is not to ask users to take the on-chain implementation on trust.

The deployed program and its transactions exist on a public blockchain, allowing the execution record to be inspected independently of the RugFreePump application.

For each demonstrated operation, users can follow the transaction signature to Solscan and inspect the corresponding Devnet transaction.

The verification path is:

```text
RugFreePump Application
        ↓
Public On-Chain Instruction
        ↓
Solana Devnet
        ↓
Transaction Signature
        ↓
Solscan
```

The RugFreePump application is the interface used to initiate the operation. The resulting transaction on Solana is the independently inspectable record of that execution.

# What This Evidence Does—and Does Not—Establish

The evidence on this page demonstrates that the RugFreePump on-chain program has been deployed to Solana Devnet, initialized, and exercised through its documented public instructions.

The linked transactions are publicly accessible Devnet records and can be inspected independently through Solscan.

This provides transparency into the existence and execution of the deployed program. It does **not**, by itself, establish that the program is free of security vulnerabilities.

This page is **not an independent security audit, formal verification, or guarantee of program security**. Users should consider the risks associated with interacting with any on-chain program and should independently review the available information before committing real funds.

The demonstrations shown here were performed on **Solana Devnet**, which is a testing environment and is separate from the production Solana mainnet environment.

The purpose of this page is to make the RugFreePump on-chain execution path visible and independently inspectable, so users can verify the underlying transactions rather than relying solely on application-level claims.
