# Proof of Execution

RugFreePump's core token lifecycle is executed by a dedicated on-chain program on Solana.

This page shows the program from compilation through deployment and initialization, followed by the execution of every public instruction used by the RugFreePump application.

More importantly, the resulting Solana transactions are publicly accessible. This allows users to verify that the operations shown in the RugFreePump interface are actually processed by the deployed on-chain program.

**Compile → Deploy → Initialize → Create Pool → Buy → Withdraw → Migrate Liquidity**

> **Network:** Solana Devnet
>
> **Program ID:** `9hpBPEiywp7FPAq5uP253eAZzdJ1Cpd36L5RAYuc9xSw`

---

## The RugFreePump On-Chain Program

The RugFreePump program contains the on-chain logic responsible for creating and operating bonding-curve pools.

The deployed program contains **53 instructions** in total:

* **49 administrative instructions** — restricted to authorized platform administration.
* **4 public instructions** — used by users through the RugFreePump application.

The public instructions are the operations that directly form the user-facing RugFreePump token lifecycle:

| Instruction         | Purpose                                                                 |
| ------------------- | ----------------------------------------------------------------------- |
| `create_pool`       | Creates a new RugFreePump token and its bonding-curve pool.             |
| `buy`               | Purchases tokens from an active bonding-curve pool.                     |
| `withdraw`          | Withdraws funds according to the bonding-curve pool's withdrawal rules. |
| `migrate_liquidity` | Migrates completed bonding-curve liquidity to a Raydium CPMM pool.      |

The administrative instructions manage platform-level operations and are separate from the public user execution flow shown below.

# Verify the Program on Solana

RugFreePump does not require users to rely solely on what the application displays.

The program has a public Solana address, and its transactions are recorded on-chain. Users can therefore inspect the deployed program and its transaction history independently.

For each operation demonstrated above, the verification path is:

```text
RugFreePump Application
        ↓
RugFreePump On-Chain Program
        ↓
Solana Devnet
        ↓
Transaction Signature
        ↓
Solscan
```

This makes the relationship between the application and the underlying on-chain execution directly inspectable.

A user can take the Program ID or any transaction signature shown on this page and inspect the corresponding Solana record independently.

# About the Verification Environment

The demonstrations on this page were performed on **Solana Devnet**.

Devnet provides the environment used to demonstrate the deployed program and its public operations without requiring real funds.

The Program ID and transaction signatures shown above correspond to publicly accessible Solana Devnet records and can be inspected independently.

This page is intended to provide transparency into the program's deployment and execution. It should not be interpreted as an independent security audit or formal verification of the program.

For mainnet interactions, users should verify that the program address presented by the production RugFreePump application matches the officially published program address and review the transaction details presented by their wallet before approving any transaction.

RugFreePump's goal is to make the on-chain component of the platform transparent and independently inspectable, rather than requiring users to rely solely on the application's interface or claims.
